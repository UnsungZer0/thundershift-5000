# Driver Controls

- GAS: prefer stronger capability.
- BRAKE: prefer cheaper/faster/local handling.
- BLINKER: temporary aside, then return.
- COAST: stay in current gear.
- GARAGE: shift to Gear 0.
- DASH: show status.
- FUEL: show resource status.
- TOW: recovery mode.
- FYI: write information to memory/handoff.
